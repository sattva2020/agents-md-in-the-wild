# corpus/

One directory per source repository, named `<owner>__<repo>`.

Each contains the agent instruction files as they exist upstream, plus a
`meta.json` recording the source URL, the blob SHA the copy was taken at, star
count, language, upstream licence and storage tier.

**These files are not mine and are not covered by this repository's MIT
licence.** They belong to the authors of the source repositories, under the
licences recorded in each `meta.json`. Entries at `metadata` tier contain no
file bodies at all — only headings and a link — because their upstream ships no
redistributable licence.

Generated by `scripts/collect.py`. Do not edit by hand.
